# rappu — portfólio em livro 3D

Livro 3D interativo (Three.js) com oito landing pages de exemplo desenhadas em canvas.

```
node server.js   # http://localhost:3000
```

Fotos: [Unsplash](https://unsplash.com) (licença Unsplash), em `assets/photos/`.
Textos de contato ficam em `CONFIG`, no topo de `js/pages.js`.
